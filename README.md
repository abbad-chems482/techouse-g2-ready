# مستودع أعضاء الفريق — Techouse G2

مرحبًا بكم في مستودع فريق **Techouse G2**! يُعد هذا المستودع دليلاً تعريفياً لجميع أعضاء الفريق. يُطلب من كل عضو رفع ملف نصي بصيغة (`.txt`) يحتوي على بياناته ومجال تخصصه.

---

## 📌 إرشادات تسمية الملف

### صيغة التسمية الإلزامية:
يجب تسمية الملف النصي وفق الصيغة التالية بدقة وبدون مسافات:

```text
<firstname><lastname>-<Specialty>.txt
```

- **الاسم:** الاسم واللقب متبوعين بفاصلة (`-`) ثم اسم التخصص (Specialty).
- **الامتداد:** يجب أن يكون الملف بصيغة نصية عادية (`.txt`).
- **تنبيه:** تجنب استخدام المسافات أو الرموز الخاصة (استخدم الحروف الإنجليزية والشرطة فقط).

#### أمثلة:
- `dalilmoulay-AI.txt`
- `sarahbenali-Frontend.txt`
- `alexturner-Cybersecurity.txt`
- `yassineb-Backend.txt`

## 🚀 طريقة رفع الملف عبر Git (خطوة بخطوة)

اتبع خطوات سير العمل القياسية (Git Workflow) لإرسال ملفك:

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/<your-org-or-username>/techouse-g2-ready.git
cd techouse-g2-ready
```

### 2. إنشاء فرع جديد (Branch)
قم بإنشاء فرع جديد باسمك:
```bash
git checkout -b feat/<yourname>
```
*مثال:* `git checkout -b feat/dalilmoulay`

### 3. إضافة الملف الخاص بك
أنشئ ملف الـ `.txt` في المجلد الرئيسي للمستودع وتأكد من صحة الاسم والمحتوى.

### 4. حفظ التغييرات (Commit)
```bash
git add .
git commit -m "feat: add <your-name> profile"
```
*مثال:* `git commit -m "feat: add dalilmoulay profile"`

### 5. رفع الفرع وفتح طلب دمج (Push & Pull Request)
ارفع الفرع إلى المستودع البعيد:
```bash
git push -u origin feat/<yourname>
```

توجه إلى صفحة المستودع على GitHub وقم بإنشاء **Pull Request (PR)** نحو فرع `main`:
- **العنوان:** `feat: add <Full Name> profile (<Specialty>)`
- **الوصف:** تأكيد بأن اسم الملف يطابق التعليمات المطلوبة.

---

## ⚠️ شروط وقواعد هامة

1. **عزل التعديلات:** قم بإضافة ملفك الخاص فقط. يُمنع منعاً باتاً تعديل أو حذف ملفات زملائك.
2. **صيغة الملف:** تُقبل الملفات النصية فقط (`.txt`). لا ترفع ملفات من صيغ أخرى مثل `.md` أو `.docx` أو صور.
3. **الالتزام بالتسمية:** سيتم رفض أي طلب دمج (PR) لا يلتزم بصيغة الاسم المحددة.
